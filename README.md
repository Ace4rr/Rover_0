## Описание

**Rover_0** — программно-аппаратный комплекс для управления автономным роботом-курьером. Проект обеспечивает маршрутизацию с использованием Yandex API, управление аппаратными компонентами, сбор телеметрии и взаимодействие с пользователями посредством Telegram-бота.

Архитектура проекта обладает выраженной модульной структурой, что позволяет легко масштабировать и расширять его функционал (например, интегрировать нейронавигацию, системы обхода препятствий и алгоритмы точной локализации).

### Поддерживаемые возможности

* **Взаимодействие с клиентами**: получение адреса доставки и отображение списка доступных роверов напрямую через Telegram-бот.
* **Интеллектуальная маршрутизация**: построение оптимального маршрута от текущего положения до адреса назначения с использованием Yandex API.
* **Навигация**: перемещение по маршруту с учетом данных GPS и одометрии, включая базовые маневры (движение вперед, остановка и т.п.).
* **Управление аппаратной частью**: точный контроль моторов, опрос датчиков и мониторинг состояния батареи.
* **Телеметрия**: регулярная отправка статуса (текущая позиция, уровень заряда, состояние движения) на центральный сервер управления.

## Запуск проекта

### Требования к окружению
*   **Платформа**: Raspberry Pi.
*   **Язык**: Python 3.x.
*   Наличие необходимых конфигурационных данных (API-ключи, токены).

### Инструкция по запуску
1. Склонируйте репозиторий с проектом:
   ```bash
   git clone https://github.com/your-username/Rover_0.git
   cd Rover_0
   ```
2. Настройте конфигурационные файлы в директории `src/config/`:
   - Внесите в `secrets.json` необходимые данные (API-ключ Yandex, токен Telegram-бота).
   - При необходимости скорректируйте параметры системы в файле `settings.py`.
3. Запустите основной скрипт программы:
   ```bash
   python src/main.py
   ```

#### Жизненный цикл после запуска:
- Инициализируется и запускается **Telegram-бот** для приема заказов от клиентов.
- Запускается фоновый цикл **сбора и отправки телеметрии** на сервер управления.
- Активируется **навигационный цикл**, находящийся в режиме ожидания задания на маршрут.

## Использование (Рабочий процесс)

Процесс обработки заказа от клиента до его завершения проходит следующие этапы:
1. **Оформление заказа**: Клиент отправляет требуемый адрес доставки через Telegram-бот.
2. **Обработка команды**: Бот принимает адрес, и через модуль `command_dispatcher.py` формируется задача на доставку.
3. **Построение пути**: Модуль `path_planner.py` обращается к Yandex API, загружая оптимальный маршрут.
4. **Навигация**: Модуль `navigator.py` инициирует движение робота, управляя аппаратной частью через `motors.py` и локализацию.
5. **Мониторинг**: На протяжении всего движения скрипт `telemetry.py` непрерывно отправляет актуальные данные на сервер.
6. **Завершение**: По достижении целевой точки доставки робот останавливается и автоматически уведомляет клиента.
